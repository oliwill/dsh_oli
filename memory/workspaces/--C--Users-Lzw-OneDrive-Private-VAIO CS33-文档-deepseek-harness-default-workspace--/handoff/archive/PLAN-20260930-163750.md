## 这是什么

本工作区不是代码仓库，而是 DeepSeek Harness（DSH）的**运维/咨询工作区**：用户在此提出 DSH 本体的安装、插件管理、兼容性排障等请求，由 agent 在本机（Windows，Electron 打包版 DSH Desktop）执行诊断与修复。

关键事实：
- DSH 运行时 0.2.0-rc.2，代码位于 `D:\Program Files (x86)\DSH\resources\app.asar`（`app.asar.unpacked\dsh` 只有原生模块）；`dsh` 命令**不在 PATH**，入口是 `D:\Program Files (x86)\DSH\resources\runtime\cli\bin\dsh.cmd`。
- DSH_HOME = `C:\Users\Lzw\.dsh`；profile 在 `C:\Users\Lzw\.dsh\profiles\`（正在使用的是 `desktop`，另有 `web`）。
- 写 `~/.dsh` 在 workspace-write 沙盒下会 `EPERM`，必须提权到 danger-full-access。
- 插件兼容闸门实现于 `@deepseek-ai/dsh-app-boot`（`evaluatePluginCompatibility`）：插件 manifest 中 `@deepseek-ai/dsh` 或 `@deepseek-ai/dsh-*` 的 peer 范围若不满足当前运行时即拒绝；豁免记录在 `<profile>/compatibility.json`。
